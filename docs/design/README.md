# Homebase design

This folder is the source of truth for UI components. When code and these
docs disagree, these docs win; update them first, then the code.

| File                           | What it holds                                                             |
| ------------------------------ | ------------------------------------------------------------------------- |
| [tokens.md](tokens.md)         | Colours, type, spacing, radius, shadow and sizes, and how they reach code |
| [components.md](components.md) | Component inventory per atomic level, with build status                   |
| [screens.md](screens.md)       | Designed screens, navigation and the templates they use                   |
| [decisions.md](decisions.md)   | Settled decisions and open questions                                      |

## Source

Copied on 2026-11-16 from the design canvas "Homebase — Mobile App Design"
(https://claude.ai/artifact/SSZmRAMhfKJ3Ngt5MML8vq): six phone screens
(390×844) and four design-system boards (foundations and atoms, molecules,
organisms, templates). Re-copy here whenever the canvas changes.

`libs/design-tokens/src/tokens.json` holds the final token values. The
canvas boards were drawn from the same values.
